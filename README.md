# yt2site

**Turn YouTube videos into a website.** You describe what you want, paste in a
few YouTube links, and an agent (Cursor) distills the videos into the pages of a
clean static website.

This repo is **agent scaffolding**: a structured workspace with clearly marked
"spots" for your input, a deterministic build pipeline, and a playbook
(`AGENTS.md`) that tells the agent exactly how to turn your videos into a site.

---

## The two spots you fill in

| What | File | Purpose |
|------|------|---------|
| **Describe the website** | `inputs/website-spec.md` | What the site is about, audience, tone, structure, what to include/avoid. |
| **List the videos** | `inputs/videos.txt` | One YouTube URL per line — the source material. |

That's it. Everything else is generated.

---

## How it works (the pipeline)

```
inputs/website-spec.md ─┐
inputs/videos.txt ──────┤
                        ▼
            scripts/fetch_transcripts.py        (1) pull transcripts
                        ▼
            content/transcripts/*.txt
                        ▼
            ── AGENT reads spec + transcripts ──  (2) author pages
                        ▼
            content/pages/*.md   +   config/site.config.yaml
                        ▼
            scripts/build_site.py                (3) render
                        ▼
            output/  (a ready-to-open website)
```

1. **Fetch** — `fetch_transcripts.py` downloads the transcript for every URL in
   `inputs/videos.txt` into `content/transcripts/`.
2. **Author** — the agent reads your `website-spec.md` and the transcripts, then
   writes the website's pages as Markdown into `content/pages/` and fills out
   `config/site.config.yaml`. (This is the step you hand to Cursor — see
   `AGENTS.md`.)
3. **Build** — `build_site.py` renders the Markdown pages + config into a static
   HTML/CSS website in `output/`.

## Quick start

```powershell
# 1. (one time) install dependencies
py -m pip install -r requirements.txt

# 2. Fill in your brief and links
#    - edit inputs/website-spec.md
#    - paste YouTube URLs into inputs/videos.txt

# 3. Pull the transcripts
py scripts/fetch_transcripts.py

# 4. Ask Cursor: "Build the site from the spec and transcripts"
#    (the agent authors content/pages/*.md per AGENTS.md)

# 5. Build the website
py scripts/build_site.py

# 6. Open it
start output/index.html
```

> On macOS/Linux use `python3` instead of `py`, and `open` instead of `start`.

## Project layout

```
yt2site/
├── inputs/
│   ├── website-spec.md      ← YOU: describe the website
│   └── videos.txt           ← YOU: paste YouTube URLs
├── config/
│   └── site.config.yaml     ← site title, nav, colors (agent fills from spec)
├── content/
│   ├── transcripts/         ← generated by fetch_transcripts.py
│   └── pages/               ← authored by the agent (Markdown w/ front matter)
├── scripts/
│   ├── fetch_transcripts.py
│   ├── build_site.py
│   └── utils.py
├── templates/               ← HTML templates (Jinja2)
├── assets/styles.css        ← site styling
├── output/                  ← generated website (open index.html)
├── AGENTS.md                ← the agent playbook
└── requirements.txt
```

See `AGENTS.md` for the exact instructions the agent follows when authoring pages.
