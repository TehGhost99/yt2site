# LearnSpanishForAll
# Aprende español para todos

**EN:** A calm, bilingual path from absolute beginner toward real conversational ability. Start with ~500 high-frequency words, practice every day, then go deeper.

**ES:** Un camino bilingüe y tranquilo desde cero hacia conversación real. Empieza con ~500 palabras frecuentes, practica cada día y luego profundiza.

## How to use this site / Cómo usar este sitio

1. **[Getting Started / Empezar](getting-started.html)** — short bilingual check-in.
2. **[Learning Materials / Materiales](learning-materials.html)** — lessons in order.
3. **[Practice / Práctica](practice.html)** — one 15–20 minute session per day.

> **EN:** Fluency grows from daily comprehensible input + retrieval, not from cramming.  
> **ES:** La fluidez crece con input comprensible y recuperación diaria, no con atracones.
