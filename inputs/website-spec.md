# Website brief — LearnSpanishForAll

## 1. What is this website about?

A bilingual (English + Spanish) practice site for absolute beginners learning
**Latin American Spanish**. Daily 15–20 minute sessions build ~500 high-frequency
words first, then go deeper. Lessons + Practice app (review → task → written checks).

## 2. Who is it for?

Absolute beginners who know only basic words and want a clear path toward fluency.
UI instructions are bilingual so learners can test Spanish while following English.

## 3. Tone & style

Friendly and encouraging, calm colors that are easy on the eyes, academically
grounded without feeling cold.

## 4. Dialect

Latin American Spanish (no vosotros as the default teaching form).

## 5. Practice model

Keep the yt2site Practice procedures: flexible day plan, local + Appwrite sync,
written checks with AI grading when configured. Session length: 15–20 minutes.

## 6. AI features

- **v1 (now):** topic / goal picker that remaps emphasis in the existing plan
- **v2 (later):** free-text “build me a program about X”
